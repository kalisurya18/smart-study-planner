# Smart Study Planner 📘

A responsive web application that helps students organize their study schedules, manage tasks, and track their daily progress.

## Features

- **Task Management:** Add and delete study tasks.
- **Priority Levels:** Categorize tasks as Low, Medium, or High priority.
- **Date and Time Scheduling:** Set a specific date and time for each task.
- **Task Completion:** Mark tasks as completed or incomplete.
- **Progress Tracking:** View your study progress as a percentage.
- **Filter and Sort:** Filter tasks by completion status and sort them by date or priority.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Use the planner on desktop and mobile screens.
- **Task Reminders:** Receive browser reminders when supported and permitted.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage API

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/kalisurya18/smart-study-planner.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional packages or installations are required.
